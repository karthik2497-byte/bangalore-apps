# Mistakes

Newest at top. One line each. Format:
`- YYYY-MM-DD — <what I assumed/did> → <what was actually true>. Rule: <do this instead>.`

- 2026-10-11 — Offered ntfy.sh as "no account needed" and wired an anonymous publish from the Pages Function → ntfy.sh limits anonymous senders per IP and Cloudflare's shared egress IPs always get HTTP 429, so no live alert arrived; Karthik then made an account and its token got 429 too (a free account has no tier, so limits stay per IP), and the alert moved to email via Cloudflare Email Routing. Rule: before offering a third-party service to a Function, check that it limits by credential, not by source IP, and make one live call from the deployed Function before calling it setup-free.
- 2026-10-10 — Polled the live privacy pages with `curl | grep mailto:<address>` to confirm the contact email deployed → Cloudflare Email Address Obfuscation rewrites every address in served HTML to `/cdn-cgi/l/email-protection#…` (decoded in the browser), so the poll failed a correct deploy for 10 minutes. Rule: check an email address on the live site in a browser (the decoded `a.href`), never in raw HTML.
- 2026-10-10 — Chained `node test-bill.mjs && sed (cache bump) && git grep` and wrote "cache thraasu-v6" into the commit and audit row → the test failed, so the bump and its check never ran; live stayed v5 and the records were wrong. Rule: never record an edit from a chain whose earlier step failed; re-run `git grep` for the value after fixing the failure, before writing it anywhere.
- 2026-10-10 — Returned a Thraasu browser test to the category grid with the on-screen back button → it calls `history.back()`, and earlier steps had stacked two Vegetables entries, so the grid never came back. Rule: late in a suite, set state directly (`cat = null; renderShelf()`) instead of replaying navigation.
- 2026-10-10 — Karthik said Print did nothing "on iPhone"; I assumed a Home Screen app without asking, and rerouted Print to an image share whenever `navigator.standalone` was true or `beforeprint` didn't fire within 1.5 s → the failing browser was Firefox Focus, and the reroute took away Safari's working print sheet. Rule: ask which browser before fixing a device-specific failure, and add a fallback beside a working native path (a separate button), never a heuristic in front of it.
- 2026-10-10 — Told Karthik to run `node scripts/browser/serve.mjs . 8811` without running it myself → the server checked paths against the unresolved root `.`, so every request was 403; `browser-smoke.sh` passes `$PWD`, so no test ever saw it. Rule: run any command exactly as you hand it to the user before handing it over.
- 2026-10-10 — Tested a `focus` handler (select-on-focus) in headless Chrome with `el.focus()` → the headless window never has system focus (`document.hasFocus()` false), so `activeElement` moves but no `focus` event fires and the handler never ran. Rule: send `Emulation.setFocusEmulationEnabled {enabled:true}` at the top of any suite that tests a focus/blur handler.
- 2026-10-10 — Diffed live `/<app>/index.html` against `dist/` with plain `curl` → Pages 308-redirects `/index.html` to `/`, so curl got an empty body and all 8 pages "differed" on a correct deploy. Rule: fetch pages by their directory URL (or `curl -L`) when comparing live with `dist/`, and in every new `verify-deploy.sh` page probe (recurred 2026-10-10: the Thraasu privacy probe failed a correct deploy).
- 2026-10-10 — Asserted day-rate fares in a MeterSmart browser test → the app auto-detects night from the clock, the run happened at night, and ₹36 read ₹54. Rule: pin clock-dependent state (`state.nightManual = true; state.nightMode = false`) before asserting a fare.
- 2026-10-10 — Read `innerText` / called `focus()` right after `switchTab()` → PowerPulse tabs fade in through a `visibility` transition, so for a frame the new tab is unfocusable and its `innerText` is empty; CSS `text-transform` also rewrites `innerText` (PG Buddy's "IS CHEAPER"). Rule: assert on `textContent`, and wait ~400 ms after a tab switch before a focus check.
- 2026-10-10 — Clicked `.frequent-approve-btn` to approve a NestHub visitor → the red Cancel Pass button reuses that class, so the test cancelled a pass. Rule: scope test selectors to their container (`#frequentVisitors .frequent-approve-btn`).
- 2026-09-07 — Wrote `scripts/build-site.sh` around `rsync --exclude` and verified it only on macOS → the Cloudflare Pages build image has no `rsync`, so the first deploy died with `rsync: command not found` (exit 127). Rule: a build script that runs in CI may only use coreutils unless the image is known to have more — `cp -R` plus `find -delete` does any exclude-copy, and the leak guard proves the prune worked.
- 2026-09-07 — Mutation-tested the `_headers` CSP guard with a `sed` whose pattern did not match → the file was unchanged, the build passed, and I nearly read that as "the guard is fine". Rule: a mutation test must assert the mutation actually applied before trusting the outcome; a no-op mutant always survives.
- 2026-08-29 — Assumed re-registering a service worker re-fetches its script with fresh response headers → Chrome served it from the HTTP cache, so the worker kept the *old* CSP and a correct fix still looked broken. Rule: when testing anything carried by a SW script's response headers, register the probe under a **new filename**; `unregister()` + `caches.delete()` + `updateViaCache:'none'` is not enough.
- 2026-08-29 — Assumed a CSP blocking a service worker's pass-through `fetch()` would surface as a CSP error → it does not: no `securitypolicyviolation` event, clean console, only a rejected promise inside the worker. Rule: to test a CSP under a SW, instrument the worker's `fetch()` and `postMessage` the failure out — a clean console proves nothing.
- 2026-08-29 — Audited XSS by grepping render functions (`renderX`, `.innerHTML = ...map(...)`) → the `showToast()` helper also builds its body with `innerHTML = icon + message` and callers interpolate user input, so NestHub and StockPing stayed exploitable for 7 weeks after the "all XSS fixed" pass. Rule: when auditing a sink, grep every helper that writes `innerHTML`, not just the ones named `render*` — toasts, modals, and tooltips are sinks too.
- 2026-08-29 — Summarised this repo's state (claimed 8 uncommitted files, "last work 2026-08-07") from a stale read → the tree was clean and five more app builds had landed since. Rule: run `rtk proxy git status` / `git log --oneline -5` before describing repo state; the rtk-wrapped `git diff` can return output that does not match the working tree.
